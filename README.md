# AI Interview Questions

A frontend web project for presenting and practising technical interview questions.

## Project overview
This repository is intended as a browser-based learning resource for interview preparation. Review the current source files to confirm the available question categories, interactions and content before extending the feature list.

## Technology stack
- HTML5
- CSS3
- JavaScript

## Run locally
1. Clone the repository.
2. Open the main HTML page in a modern browser, or serve the project using a local static web server.
3. Navigate through the available question content and test the implemented interactions.

## Suggested learning use
Use the questions as prompts for active recall: attempt an answer first, explain the reasoning aloud, and then compare it with a trusted reference. Keep answers and examples technically accurate and version-aware.

## Future improvements
- Organize questions by role, topic and difficulty.
- Add search, filters and bookmarks.
- Add answer explanations and runnable coding examples.
- Add quiz mode, progress tracking and accessibility support.
- Add tests for navigation and quiz behaviour.

## Project status
Learning / interview-preparation frontend. The exact question coverage is determined by the content currently stored in the repository.
